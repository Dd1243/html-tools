从素材到网站图标

  1. 选一张清晰 Logo，或输入一个字与 Emoji。横向 Logo 可选择完整保留，再调整留白。
  2. 查看 16 像素预览。如果细线和文字已经难辨认，先简化素材；放大原本模糊的图片不会增加细节。
  3. 下载完整 ZIP 包。PNG 直接从原始素材按目标尺寸绘制，不经由小预览放大。
  4. 部署文件并加入安装标签。首次验证时直接打开图标地址，检查返回的是图片或 manifest，而非 HTML 错误页。

Favicon 常见问题

PNG 和 ICO 应该用哪个？

PNG 便于预览、编辑和按尺寸引用；ICO 把 16、32、48 像素图像放在一个文件里，浏览器可按需要选择。本页下载的是实际 ICO 文件，不是改扩展名的 PNG。完整包同时提供两种格式。

为什么换好图标，浏览器还是显示旧图？

先直接访问部署后的图标 URL，并确认页面 head 中的路径正确。浏览器、CDN 与 Service Worker 都可能缓存旧图。可更新图标文件名或给引用地址加版本参数，再清理对应缓存；仅刷新页面不一定会更新 favicon。

为什么 Emoji 在不同电脑上看起来不一样？

文字和 Emoji 使用当前设备的系统字体绘制，字形、颜色和垂直位置可能不同。导出的 PNG 与 ICO 已经是固定图像，部署后不会继续随访问者字体改变。若要跨设备获得统一的制作效果，请上传你已确认样式的图片。

SVG 和透明图片有哪些限制？

SVG 由浏览器作为图片解码，依赖外部字体、脚本或外部图片的 SVG 可能无法完整显示。建议先把文字转为路径、嵌入素材，再检查预览。透明背景只用于浏览器图标；Apple 与 manifest 图标会使用你选择的背景色铺底，避免黑色或不确定底色。

图标会自动出现在搜索结果里吗？

文件与标签是提供图标的基础，不保证搜索引擎一定展示。建议使用易辨识的正方形素材，并允许抓取页面和图标；完整包另提供 64 像素 PNG。可按 Google 网站图标说明检查实际部署，抓取与更新需要时间。

这个工具能自动发布到我的网站吗？

生成与下载在浏览器本地完成，不会登录或修改你的网站。你需要上传文件并加入安装标签。导航和广告需要联网，核心图标处理不依赖远程服务。
