如何把 GIF 拆成图片

GIF 动图由连续的画面和各自的停留时间组成。这个工具会按照动画的原始顺序还原画面，再把需要的帧保存为静态 PNG。你可以用它提取表情包中的一个动作、选择文章封面，或检查设计稿里的动画节奏。处理在当前浏览器中完成，不需要注册，也不需要把素材发送到服务器。

  1. 打开文件。把一个 GIF 拖入上方区域，或点击选择文件。手头没有素材时，可以先用示例 GIF 熟悉操作。
  2. 逐帧检查。解析完成后，在预览下方拖动滑块，或使用上一帧、下一帧按钮查看画面。播放按钮用于连续预览，旁边会显示当前帧号及原始延迟。
  3. 选择画面。需要连续片段时，填写起始帧、结束帧和取帧间隔，再按范围选择；只需要零散画面时，可以直接勾选下方的缩略图。
  4. 保存结果。“保存当前帧 PNG”下载预览中的那一张图片；“下载所选帧 ZIP”把已经勾选的图片打包成一个文件，适合批量整理。

怎样选择帧范围与间隔

页面中的帧号从 1 开始。起始帧和结束帧都包含在选择范围内，间隔以起始帧为基准计算。例如，希望从第 10 帧到第 20 帧之间每隔两帧取一张，可以设置起始为 10、结束为 20、间隔为 2，得到第 10、12、14、16、18、20 帧。间隔为 1 则保留这个范围内的每一帧。

范围选择适合从长动图中快速截取一个动作，也适合降低导出图片数量。若只需要某几个关键画面，先在预览区找到它们，再勾选对应缩略图会更方便。“清空选择”只取消导出的勾选状态，不会删除已经解析的动画；可以随时重新选择或用“全选”恢复。

帧延迟、总时长和画布尺寸怎么看

每帧旁的毫秒数表示 GIF 文件中记录的停留时间，100 毫秒等于 0.1 秒。不同帧可以具有不同的延迟，因此平均帧率不能完整反映动画节奏。检查停顿、转场或循环衔接时，更应该关注具体帧的延迟。总时长是文件中各帧延迟的合计，表示动画播放一次的记录时长。

有些 GIF 把延迟记为 0，浏览器播放时通常会给它一个最低停留时间，因此实际预览可能比记录的总时长更长。导出的 PNG 只有画面，不包含播放时长。若要重新组成动图，需要在 GIF 制作工具中另外设置播放速度，并参考当前文件的原始延迟。

画布尺寸指完整 GIF 的宽度和高度，也是 PNG 导出的尺寸。为了节省体积，GIF 内部的某一帧可能只保存发生变化的小区域。本工具会把这些局部变化叠加到对应画面，并根据透明色、画面位置和帧处置方式还原整张图片，避免把局部色块误当成完整的一帧。

导出图片时需要注意什么

PNG 能保留透明背景，适合继续做设计或裁剪素材。预览中的灰白方格只用来表示透明区域，不会写进导出的图片。如果目标平台只接受 JPG，建议先在图片编辑工具中添加所需背景色，再进行格式转换，以免透明区域变成不合适的颜色。

ZIP 中的图片按原始帧号命名，便于按顺序查看，也方便向同事指出具体画面。只挑选部分帧时，文件编号可能不连续，这表示保留了它们在原动画中的位置。保存前可以检查“已选择”的数量，避免把整段动画都导出后再逐张删除。

将 GIF 拆成 PNG 不会为原图补充新的细节。GIF 的调色板和像素信息已经由源文件决定，PNG 只是以静态图片的形式保存还原后的画面。它也不是视频转换或 GIF 剪辑工具：这里不会生成新的动图，也不会改变源 GIF 的速度、循环次数或文件大小。

文件处理与使用限制

工具支持 GIF87a 和 GIF89a 文件。文件名以 .gif 结尾并不代表内容一定是 GIF；把其他图片重命名为 GIF 不能完成转换。文件无法解析时，先在系统图片查看器中确认它能正常打开，再重新选择原始文件。对于传输中断、数据不完整或不符合格式的文件，工具会提示错误。

动画的文件体积与解码后的内存占用并不相同。一张尺寸较大、帧数很多的 GIF，即使压缩后不大，展开为完整画面也需要更多内存。手机或较旧电脑处理这类文件会更慢；解析过程中可以取消，并换一个尺寸更小或时长更短的素材。帧序列采用分批展示，缩略图尚未全部显示时仍可选择整个范围。

原始文件在设备本地读取，拆帧与打包也在本地完成。页面不会保存你的素材或上传历史，刷新、关闭页面或更换文件后需要重新解析。完成后请及时下载结果。保存这个 HTML 页面后，核心拆帧功能也可以离线使用；外部网页导航及网站通用资源则需要网络连接。

常见问题

为什么有些相邻帧看起来完全一样？

源动画可能通过重复画面或延长某帧停留时间制造停顿。相邻帧看起来相同不一定是解析错误，可以结合帧号和延迟查看。工具按原顺序保留帧，不会自动删除相似画面；导出时可以只勾选其中一张。

只想保存正在预览的一张图片，需要先勾选吗？

不需要。点击“保存当前帧 PNG”会直接下载预览中的当前帧。缩略图上的勾选状态用于控制 ZIP 的内容，两种下载操作可以独立使用。

为什么导出的图片数量和 GIF 总帧数不同？

ZIP 只包含当前选中的帧。设置间隔或取消勾选后，导出数量会少于总帧数；先查看右侧的选择数量。需要全部画面时，点击“全选”再下载 ZIP，而不是依次下载多个文件。

拆帧后还能保留透明背景吗？

可以。PNG 保存还原画面的透明区域，预览用的方格背景不会被导出。但源 GIF 本身已经带有的白色或其他实色背景不会被自动去除，这需要另外进行背景处理。

素材会发送到服务器吗？

不会。文件读取、帧解码、图片生成和 ZIP 打包都在当前浏览器内完成，无需上传素材。若在公共设备处理文件，请同时留意浏览器下载目录中的导出图片，并在使用后自行清理。
