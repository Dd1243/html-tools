字段检查

    表单和导入内容仅在当前页面内存中处理，不上传、不自动保存。核心生成和导入功能可离线使用。

    把页面信息整理成可发布的 head 代码

    网页标题、搜索摘要和分享卡片使用的字段各有用途。这个生成器把它们放在同一处编辑：先填写页面内容，再核对预览和检查提示，最后复制 HTML 片段。工具在浏览器内处理输入，不抓取填写的网址，也不会把草稿上传到服务器。

    先分清三组信息

    title 与 description 描述当前页面；Open Graph 面向支持该协议的分享平台； twitter:* 字段用于 X 卡片。社交标题可以比页面标题更适合分享，但应描述同一份内容。覆盖字段留空时会沿用上游文案，预览与生成代码使用相同的继承规则。

    页面网址表示这份内容的分享地址，canonical 表达你希望作为规范版本的地址。两者通常相同，也可能因参数页或重复内容而不同。请使用完整的 HTTP(S) 网址；工具保留查询参数，不会猜测哪些参数可以删除。canonical 的片段标识会移除并给出提示，避免把页内位置作为规范版本。

    字符数用于编辑，预览用于比较

    中文、英文、数字和表情占用的显示宽度不同，同样的字符数不一定显示成同样长的标题。Google 没有为标题和元描述规定固定字符上限，实际展示会受设备宽度、查询及页面内容影响。这里的计数帮助比较不同文案，不会按所谓标准长度自动截去你的输入，也不会按长度给页面评定排名分数。

    搜索与社交预览只模拟排版。搜索引擎可能重新选择标题或生成查询相关的摘要，分享平台也有自己的抓取、裁切和缓存行为。请把关键信息放在前面，避免重复堆叠词语；上线后仍应检查目标页面的原始 HTML 和实际分享结果。

    图片网址与预览占位

    分享图片需要填写平台能够访问的绝对网址。工具只把该网址写入标签，预览用占位区域表示图片布局，不会自动请求图片，也不会把浏览器临时地址写进生成代码。图片是否公开可读、是否受到登录限制或防盗链影响，需要在发布环境中另行确认。

    填写图片时也应补充准确的替代文本，描述图中与分享内容有关的信息。选择大图或摘要卡片后，检查主体是否适合相应裁切方式。图片尺寸建议是一种制作参考，不能保证所有平台都采用同样的比例或展示完整画面。

    导入现有 HTML 后，应检查什么

    本地导入适合整理已经存在的页面头部。工具只提取当前支持的字段，遇到重复标签会提示并按界面说明选择取值，不会执行源码中的脚本或加载样式、图片。生成结果是重新整理的片段，不是原文件的无损备份；未支持的自定义标签、验证代码和分析脚本仍应由你在原项目中保留。

    如果 CMS、主题或 SEO 插件已经输出标题、描述和 canonical，应在原有配置中更新，避免再粘贴一套。字符集和 viewport 默认不输出，只有确实需要时才勾选。把代码放进 HTML 的 head 后，检查最终响应中的标签，而不只看浏览器里动态修改后的 DOM。

    robots 与 canonical 分别解决什么问题

    不填写 robots 时，通常无需再显式输出默认的 index, follow 。需要排除搜索展示时才使用 noindex ，并确保搜索引擎能够抓取页面、读取该指令。robots.txt 阻止抓取与页面中的 noindex 并不是同一件事，也不应把 noindex 当作选择规范网址的方法。

    canonical 是规范化信号，不是强制跳转，也不保证搜索引擎一定采用。对于重复页面，应同时检查站内链接、重定向和站点地图是否指向一致的版本。本工具检查字段与明显冲突，不会访问页面验证收录状态。高级选项中的 keywords 仅为兼容既有系统；Google 搜索不使用该标签进行索引或排名。

    常见问题

    为什么关掉一个标签组后，预览也会变化？

    生成代码只包含启用的标签组。预览应帮助核对本次准备发布的字段；关闭 Open Graph 或 X 后，应以相应界面状态判断，不能把未输出的字段当成已发布内容。

    为什么生成结果没有写入网站名称？

    网站名称需要填写你自己的品牌或站点名。工具不会把 WebUtils 注入其他网站的代码，也不会为空字段编造名称。检查原页面时，还应确认主题没有重复输出其他 og:site_name。

    复制按钮不可用时怎样取走代码？

    浏览器可能因权限或运行环境限制剪贴板。使用界面提供的手动复制区域，或下载 HTML 片段。下载内容应与当前生成代码一致；输入有错误时，先修改对应字段再重新导出。

    刷新页面后，刚才的内容还能恢复吗？

    草稿不会自动保存到本地存储或分享链接。需要保留时请及时下载代码；主题偏好可单独保存。保存下来的代码包含你填写的网址和文案，分享前请核对内容。
