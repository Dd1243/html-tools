    怎样用预览检查标题与描述

    这个工具适合在发布前检查一页内容的标题、描述和地址是否表达一致。左侧是完整编辑值，右侧是本地绘制的搜索摘要示意，下方是可以复制的标签片段。它不会提交页面到搜索引擎，也不会读取线上搜索结果。你可以从空白开始，或者把已有页面的源代码导入，先弄清实际声明的标签，再调整文案。清空之后保留真正空白的输出，不会把示例标题或工具站点的地址写进你的网站。

    像素测量说明了什么

    相同字符数量的标题，显示宽度可能相差很大。英文里的窄字母与宽字母、中文、数字、标点和表情占用的空间不同，浏览器选用的字体也会影响结果。这里使用 Canvas 按当前预览字体测量完整单行文本，并用 Unicode 码点计数，避免把常见表情简单当作两个字符。码点也不等同于人眼看到的字形数量：组合音标或家庭表情可能由多个码点组成，因此计数是透明的编辑参考，不是语言学上的字数。

    预览容器使用固定的可见行数，并根据当前可用宽度换行。工具检测到内容超出可见区域时提示“当前示意可能截断”，但不会删除输入中的任何尾部文字。单行像素宽度和多行是否溢出是两个不同指标；日期文字单独显示，避免把日期长度误算成描述本身。切换桌面与移动模型、改变窗口宽度、选择另一搜索布局，都可能改变可见行数中的内容。JSON 会记录本次字体、容器宽度与测量数据，便于理解这次截图是在什么条件下生成的。

    示意与真实搜索结果的区别

    Google、Bing 与百度按钮只切换本工具的排版模型。搜索引擎可能根据页面标题、主标题、正文、链接文字等信息生成标题链接，也可能因查询不同而选择另一段摘要。meta description 是一个可供参考的页面描述，并不保证被原样采用。搜索引擎并没有本工具可以承诺的固定字符截断线；不要为了凑满某个数字而扩写无用内容，也不要看到当前框里放得下就断言真实搜索结果一定完整显示。

    写标题时，先让读者知道这一页的具体主题，再检查过长的站点后缀是否挤占空间。写描述时，说明页面实际提供的内容、适用情境或范围，避免把多个关键词拼成缺少信息的句子。工具提示标题或描述缺失，是提醒你确认发布意图；它不会给标题打排名分，也不会保证一段文案能提高点击率。站点名称和日期只是展示上下文，不会被自动拼进 title，也不会生成未经确认的发布日期标签。

    安全导入与首项规则

    完整 HTML 只提取 head 直属的受支持标签；片段只读取顶层标签。正文里的 title 字样、脚本字符串、模板内容、noscript 和 SVG 等外来命名空间不作为页面元数据。导入使用隔离的惰性文档，脚本不执行，图片、样式表与框架不会被加载到当前页面。本地文件按 UTF-8 解码，并检查文件大小与源码长度。解析失败会清空旧字段并禁用导出，避免把上一次成功的内容误认为这一次的结果。

    源标签表保留顺序、重复和值为空的标签。提取采用首项，首项为空也保持空白，不用后面非空值掩盖发布错误。这是本工具帮助定位模板问题的约定，不代表所有搜索引擎处理重复标签的具体优先级。og:title 和普通 title 有不同用途，本工具不会互相顶替。导入还会提示 robots 中的 noindex、nosnippet 等限制；这些指令仅作为源信息检查，不会被悄悄改成新的输出标签，真正发布时仍需要核对服务器和页面里的实际设置。

    URL 与导出的边界

    编辑区的 URL 接受无凭据的完整 HTTP(S) 地址。相对路径、执行脚本的协议、反斜杠、空白或带用户名密码的地址会阻止导出，给出修复提示。合法地址按填写的原值输出，不自行去掉参数、片段或修改主机大小写，因此你仍需自己确认它是否是想声明的 canonical。留空则不输出 canonical，不从预览站点、输入来源或工具页面地址补造一个值。

    导入时，若 canonical 是相对路径，可以填写页面 URL 作为解析基准；源码首个带 href 的 base 元素会参与换算。绝对 base 可以独立使用，相对 base 没有页面基准就不能碰巧借用当前工具的地址。第一个 base 无效时会提示并只回退有效页面 URL，不采用后面的 base。报告同时保留 canonical 原值和解析地址，方便检查构建产物。源码或解析基准变化会清空旧字段并使旧来源失效；点击提取后填入新字段，后续手动编辑会标记来源已经变化。

    HTML 下载是一段完整值经过安全转义后的标签片段，不是原始网页。连续空白折叠为一个空格、首尾空白移除，是为了让预演与标签文本一致；JSON 同时保留编辑原文和规范化值。复制权限被浏览器阻止时，工具会选中文本供你手动复制。核心编辑、提取与下载都在浏览器本地完成，可以离线使用；站点广告和同意管理资源仍按站点配置运行。

    可参考 Google 标题链接说明 与 搜索摘要说明 理解自动生成机制。发布后请结合实际页面和搜索引擎提供的检查工具验证，避免把本地示意当成收录证明。
