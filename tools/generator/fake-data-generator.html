从配置到可复用的测试样本

  1. 选择中文或英文，并勾选 API 或数据表需要的字段。
  2. 设置 1–1000 条记录；记录种子，便于团队复现同一份样本。
  3. 生成后切换 JSON、CSV 或 SQL，复制或下载当前显示的内容。

修改配置后，现有结果会保留，点击“生成测试数据”才应用新配置。切换格式不会改变已生成的值。

示例数据的边界

邮箱统一使用 example.com；IP 使用文档示例网段。中文电话为 138****1234 形式的脱敏占位符；英文电话使用 202-555-01xx 示例范围。

姓名、公司和地址是有限词库的组合，可能重复或与现实信息巧合。记录编号以 MOCK- 开头，不生成身份证号；这些样本适合演示与联调，不代表经过真实身份、送达或业务规则验证的数据。

使用前你可能想知道

随机种子能让别人复现同一份数据吗？

可以。在此版本中，使用相同种子、语言、字段顺序和数量，会得到相同结果。种子适合写进测试用例；它并非密码或安全令牌。改变数量时，前面相同数量的记录仍会保持一致。后续词库或算法更新可能影响结果，长期固定样本建议同时保存下载文件。

JSON、CSV 与 SQL 该怎么选择？

JSON 适合接口响应与前端 fixtures。CSV 包含字段名表头，并处理双引号、逗号和换行；下载带 UTF-8 BOM，方便电子表格识别中文。以等号等字符开头的 CSV 文本会添加单引号，避免作为表格公式执行。SQL 导出面向 SQLite 的 INSERT 语句，字段值均为文本；请先建立相应表结构，其他数据库需确认标识符与字符串转义规则。

为什么没有身份证号或完整中文手机号？

本工具侧重可识别的测试占位内容，因此提供模拟记录编号和脱敏中文电话。若要验证身份证校验位或手机号号段，应另外为特定规则编写明确的测试样例。不要把此处样本用于发送邮件、拨号、身份认证或联系真实用户。

和 Faker 这样的开源库有什么区别？

本页提供无需安装的精简词库与常用导出功能，不加载 Faker。需要更多国家地区、复杂字段或大规模自动化时，可使用开源库编写脚本；本页更适合快速准备小批量演示数据。生成器不读取你的业务数据，也不把结果写入浏览器存储。
